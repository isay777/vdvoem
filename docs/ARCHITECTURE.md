# Архитектура MVP

## Поток данных

Мобильное приложение сначала читает SQLite-кэш, затем синхронизируется с PostgreSQL. Каждая локальная мутация получает UUID и сохраняется в `pending_mutations`. RPC `apply_versioned_mutation` обеспечивает идемпотентность по `client_request_id` и сравнивает `expected_version`. При расхождении клиент показывает обе версии и требует явного выбора.

Supabase Realtime используется как сигнал перечитать доступные записи. RLS применяется к каждому запросу и событию; интерфейс не является границей безопасности.

## Пары и приглашения

В `couple_members` действует частичный уникальный индекс: один пользователь может иметь не более одной активной пары. `accept_invitation` блокирует приглашение, повторно проверяет срок и число участников, поэтому два одновременных запроса не добавят третьего человека.

Ссылка содержит 64-символьный случайный токен. В БД хранится SHA-256, а шестизначный код детерминированно выводится из токена и также хранится только в виде хеша. Ошибочные попытки ограничиваются на аккаунт.

## Выход и удаление

`leave_couple` закрывает пару транзакционно, отзывает приглашения и push-доступ. Общие сущности копируются каждому участнику как независимые приватные записи; личные желания остаются у владельца. Будущая пара не получает архив автоматически.

Удаление аккаунта ставится в очередь на семь дней. Edge Function удаляет пользователя через Admin API. Внешний ключ `created_by` обнуляется, поэтому копия бывшего партнёра сохраняется без идентифицирующего профиля. Объект фотографии сохраняется, пока существует хотя бы одна запись `asset_access`.

## Уведомления

Триггеры добавляют нейтральные сообщения в `notification_outbox`. Edge Function отправляет их через Expo Push Service, отключает невалидные токены и никогда не помещает содержание записи в lock-screen body. Маршрут и UUID передаются в data payload, после открытия запись всё равно проходит RLS-проверку.

## Часовые пояса

События со временем хранятся в UTC плюс IANA timezone. All-day события хранят локальные даты отдельно, поэтому не сдвигаются при смене часового пояса. Напоминания пересоздаются при изменении или отмене события.
