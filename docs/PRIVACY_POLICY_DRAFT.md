# Проект политики конфиденциальности «Мы вдвоём»

> Черновик необходимо дополнить юридическими реквизитами оператора, страной обработки, контактами и фактически выбранными поставщиками до публикации.

## Какие данные обрабатываются

Приложение обрабатывает email для входа, имя, аватар, часовой пояс, настройки уведомлений, push-токены, созданные пользователями списки, события, заметки, ссылки и фотографии. Для защиты приглашений временно сохраняются технические сведения о попытках их принять. Пароли не собираются: вход выполняется одноразовым кодом на email.

## Для чего используются данные

Данные используются только для предоставления приватного пространства пары, синхронизации между устройствами, доставки выбранных уведомлений, восстановления сессии и предотвращения несанкционированного доступа. Содержание списков не используется для рекламы и не включается в технические логи.

## Поставщики

- Supabase: аутентификация, PostgreSQL, файловое хранилище, realtime и серверные функции.
- Expo: сборка приложения и доставка push через APNs/FCM.
- Выбранный SMTP-провайдер: доставка одноразовых кодов.
- Apple и Google: магазины приложений и платформенная доставка push.

Фактические регионы размещения и ссылки на политики поставщиков следует указать после создания production-проектов.

## Доступ и хранение

Общие данные доступны только двум активным участникам пары. Сервер проверяет права для каждой записи и фотографии. При выходе из пары синхронизация прекращается, а каждому участнику остаётся отдельная приватная копия общих данных. Личные желания остаются у создателя.

Удаление аккаунта можно отменить в течение семи дней. После этого удаляются профиль, email-сессии, устройства и личная копия пользователя. Копия бывшего партнёра сохраняется без имени и аватара удалённого пользователя. Неиспользуемые фотографии удаляются после исчезновения последнего права доступа.

## Права пользователя

Пользователь может исправить профиль, отключить категории уведомлений, выйти из пары, запросить удаление аккаунта и обратиться к оператору для доступа, выгрузки или удаления данных в объёме, предусмотренном применимым законодательством.

## Безопасность

Используются TLS, приватные storage buckets, PostgreSQL Row Level Security, одноразовые приглашения, ограничение попыток, короткоживущие подписанные ссылки и раздельное хранение серверных секретов. Текст push по умолчанию не раскрывает содержание пары на заблокированном экране.
